## Free Netlify address
Netlify gives each site a free `*.netlify.app` address. Upload the extracted EqualLearn folder in Netlify Deploys, then choose **Site configuration → Change site name**. Try names such as `equallearn`, `equallearn-lms`, or `equallearn-jardeleza`; the exact name must be available.

A real `.com` such as `EqualLearn.com` is a paid custom domain if available. Netlify hosting can remain free even when a purchased custom domain is attached.

If you switch the live website away from GitHub Pages, update the `server.url` value in `capacitor.config.json` and rebuild the APK so the app opens the new website.
