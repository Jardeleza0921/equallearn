# Phase 2.3 — Navigation and Design Studio Refinement

- The EqualLearn logo is now the desktop sidebar collapse/expand control.
- Settings now sits with the normal Admin/Teacher/Student navigation items instead of being isolated in the sidebar footer.
- Logout was removed from the sidebar navigation and remains in the profile popover.
- Settings was removed from the profile popover.
- The Admin Design Studio now uses a draft → preview → explicit save workflow.
- Design controls are grouped into Public Page, Page Content, and Global Appearance sections.
- Added controlled global options for density, cards, hero treatment, content width, and corner style.
- Saved design preferences remain browser-local in this phase; Firebase remains untouched.
