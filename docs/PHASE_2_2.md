# Phase 2.2 — Interaction and Design Polish

- Public pages expose visible non-dropdown theme controls.
- Admin, Teacher, and Student workspaces keep theme controls inside Settings only.
- Desktop workspace side navigation can collapse to icons and remembers the choice locally.
- Notification bell opens an interactive notification center.
- Profile control beside the bell opens account, settings, and logout actions.
- Profile pictures can be previewed locally with initials as the fallback. Shared file persistence remains reserved for Appwrite Storage.
- Admin includes a Design Studio for safe browser-side preview of public page titles, descriptions, density, and card treatment.
- Firebase Authentication and Firestore structure are unchanged.
